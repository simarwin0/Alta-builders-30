# Alta Public AI Code Reviewer

A public, no-login code review app deployed as a standalone Render service. Anyone can open the website and submit a source file without creating an account or entering a password.

## Features

- Public access: no Google sign-in, no owner password, and no account required.
- AI-powered review for bugs, security issues, and maintainability concerns.
- Paste code or submit a public GitHub file URL.
- Google Gemini API with structured JSON output validation.
- Submitted source is treated as untrusted text and is never executed.
- Request size limits, same-origin checks, per-IP rate limits, and a shared daily review allowance.
- Source code is not saved to a database or review history.

## Render setup

- Root Directory: leave blank
- Runtime: Node
- Build Command: `cd ai-code-reviewer && npm install --no-audit --no-fund`
- Start Command: `cd ai-code-reviewer && npm start`
- Health Check Path: `/health`

## Required environment variables

| Key | Value |
| --- | --- |
| `NODE_ENV` | `production` |
| `GEMINI_API_KEY` | Your Google Gemini API key |
| `GEMINI_MODEL` | `gemini-2.5-flash` (optional; default) |
| `MAX_REVIEW_CODE_CHARS` | `30000` (optional; default maximum source size) |
| `MAX_DAILY_REVIEWS` | `250` (optional; shared daily allowance, minimum 25, maximum 5000) |

Keep the Gemini API key only in the Render environment settings. Do not put it in browser code or GitHub. This app does not need MongoDB, a JWT secret, reviewer password, Google OAuth credentials, or login-related environment variables.

## Public access and usage limits

Visitors do not pay and do not need to register. The owner of this app pays for the Gemini API usage generated by reviews. To reduce unexpected usage:

- Each IP address can submit up to 5 reviews per minute.
- Each IP address can submit up to 25 reviews per rolling 24-hour window.
- The whole service shares a rolling 24-hour allowance, defaulting to 250 reviews. Set `MAX_DAILY_REVIEWS` in Render to change it.

These rate limits use in-memory counters on the Render instance. They reset if the service restarts or redeploys, so they are basic abuse and cost controls, not a billing guarantee. Use Google AI Studio usage limits as an additional safeguard.

## Routes

- `GET /` — public reviewer interface.
- `GET /health` — public service status and usage-limit settings.
- `POST /api/analyze` — public code review endpoint. No session or login is required.

## Local development

```bash
cd ai-code-reviewer
npm install
GEMINI_API_KEY=your_key npm start
```

Then open http://localhost:10000.

## Safety notes

- The reviewer analyzes source as text only; it does not execute or compile submitted code.
- Only public GitHub file URLs are supported. Private repositories and whole-repository URLs are not fetched.
- AI findings are suggestions, not proof. Verify them and test proposed changes manually.
- Submitted code is processed to produce the response and is not written to a database by this service.
